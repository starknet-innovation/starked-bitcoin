Bitcoin's coin set, proven in one proof

One STARK proof covers Bitcoin's header chain from genesis, every block from 935,001 to 972,500, and the full coin set after block 972,500. This page checks that proof in your browser, then checks any coin against the set it proves. No server is trusted: it only supplies data, and your browser recomputes everything.

Step 1

Verify the seal

Downloads the header-chain file and the seal (about 1.6 MB) and checks them with the same verifier as chainproof verify-seal, compiled to WebAssembly. Every verifying key is built into the verifier.

Step 2

Check a coin

Enter an outpoint as txid:vout. The server returns its Merkle path (about 1 KB). Your browser checks the path against the root of the seal from step 1. A coin that is absent gets a proof of absence: the two neighbouring coins in the sorted set.

Or check a proof file (.sbmember) without the server

What the proof shows, and what it does not, is in the repository's docs/design/chain-seal.md. This is a preview: the proof system and its Lean soundness statement have not been externally reviewed.
